Datos personales

@if (isInvalidField('nombre')) {
Introduce un nombre de entre 2 y 30 letras.
}
@if (isInvalidField('apellidos')) {
Introduce unos apellidos de entre 2 y 50 letras.
}
@if (isInvalidField('dniNIE')) {
Introduce un DNI o NIE válido.
}
@if (isInvalidField('telefono')) {
Introduce un teléfono móvil español válido.
}

Datos de la cuenta

@if (isInvalidField('nombreUsuario')) {
Debe tener entre 4 y 15 caracteres, empezar por una letra y usar solo letras, números o guion bajo.
}
@if (isInvalidField('email')) {
Introduce una dirección de correo válida.
}
@if (isInvalidField('password')) {
Debe tener entre 8 y 20 caracteres e incluir mayúscula, minúscula, número y símbolo.
}

Preferencias de formación

@if (isInvalidField('cursoInteres')) {
Selecciona un curso de interés.
}
@if (isInvalidField('horasDisponibles')) {
Indica entre 2 y 40 horas semanales.
}
@if (isInvalidField('codPostal')) {
Introduce un código postal español válido de 5 cifras.
}
Los campos marcados con * son obligatorios.
